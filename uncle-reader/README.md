# Uncle Reader — Source-locked bilingual UI

**Public UI:** https://developer-fandom-rush.github.io/Midnight-bet/uncle-reader/

## What is implemented
- Episode navigation for E01–E68 once the private dataset is loaded.
- Two aligned columns: original RAW (left) and line-matched Hinglish (right), sharing exactly the same E##-L### source ID.
- Evidence-anchored **mood before the encounter**, showing each character's known circumstances and source line ranges; separate *after/outcome*.
- Filters for Uncle–Dhika, Uncle–Sharmi, whole episode, and verified translation only.
- Search, copy citation, QA report export, private local data import and optional retention in browser localStorage.
- **No invented Hindi translation** when no reviewed translation exists. Those rows prominently say PENDING.
- Separation of neighbour Uncle from plumber Iroh.

## Private source dataset
The complete extracted RAW is **not committed to this public GitHub repository**, because the original story is third-party material. Private copy is in Google Drive:
[Stories → DHIKA Story → UNCLE_READER](https://drive.google.com/drive/folders/12gTy59nYAqdZreEJLx_PlM6LfvUv5FGu)

The Drive folder contains a **self-contained offline HTML reader** with private RAW embedded. Download that HTML and open it in a browser: no import required.

To read the public GitHub Pages UI with complete RAW, use **Open private dataset** to select the JSON file delivered to the user separately. It is parsed only in the browser, not uploaded to GitHub; if localStorage is available it can be retained on that device.

- 68 original episodes E01–E68 indexed, 13,638 nonblank RAW rows.
- 694 Uncle–Dhika evidence-tagged rows and 92 Sharmi–Uncle rows (some overlap).
- 264 line-specific Hinglish translations reviewed in eight episodes: E01, E02, E05, E39, E42, E46, E49, E56.
- 18 episode-level mood records grounded to line ranges.
- **Zero mismatches** among the mapped evidence-ledger lines versus complete RAW source.
- **Not** claimed: full Hindi translation, exhaustive tagging of all Uncle-relevant lines, or final author-style interpretation for E01–E68.

## Why this workflow prevents earlier mistakes
1. RAW is an immutable, separately stored source; not generated by the AI.
2. Every translated row keeps the same episode and original line number.
3. Missing translations stay empty rather than being replaced with vague paraphrases.
4. Pre-encounter mood, observable events, post-encounter outcomes and interpretations are separate data fields.
5. Every significant character claim must point to original source lines.
6. Character knowledge is tracked by episode; do not retrospectively import future knowledge.
7. Future story ideas are **not** inserted into this reader's canon evidence.
